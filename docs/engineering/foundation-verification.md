## Self-review and operational boundaries

- Authentication uses Argon2id; session/CSRF values are HMAC-SHA256 hashes in the database.
  Cookie replay after logout, expiration, tampering and missing/mismatched CSRF are tested.
- Login counters persist across factory restarts, cap counts and prune expired windows. A valid
  login removes only its own reservation, preserving prior failed attempts. Peer identity comes
  from ASGI, with arbitrary forwarded headers ignored by the application.
- Project changes use workspace + active-row + expected-revision predicates. Concurrent PATCHes
  using the same revision produce one success and one409, without a lost write.
- JSON serializers whitelist safe fields; request validation excludes submitted values and contexts.
  Error containment prevents raw unexpected exceptions reaching ASGI traceback logs. Stream failures
  abort using a sanitized message after headers; partial bytes are not claimed as a complete file.
- Local object keys reject absolute paths, traversal, separators and resolved symlink escapes.
  The local storage root must be owned exclusively by the service user. Production bucket policy,
  private connectivity, IAM, HTTPS proxying and storage durability require deployment verification.
- Object storage and the database are not one distributed transaction. Handled failures clean up;
  crashes or uncertain remote deletes require an orphan-reconciliation mechanism in durable execution.
- Project and asset collections enforce `limit=50` by default, valid range 1–200, and nonnegative
  offset. SQL count and page queries share the owned/active filtering predicates; totals describe
  the complete filtered collection. Stable ordering is `created_at DESC, id ASC`. Tests seed 150
  rows with timestamp ties plus foreign/deleted neighbors, check offset pages and empty final pages,
  reject invalid bounds with 422, and preserve foreign/deleted project 404 behavior.
- This macOS environment intermittently applied the `hidden` file flag recursively to ignored
  `.venv` files. CPython skips hidden `.pth` files, temporarily breaking editable imports despite
  valid package metadata. Clearing `hidden` on the two `.pth` files restored normal imports for
  verification. This local filesystem issue is not a source-code workaround or cloud failure.

## Public interfaces for durable execution

- `config.Settings` and `app.create_app(settings)` construct an explicit runtime.
- `db.Base`, `make_engine`, `make_session_factory`, and `get_db` establish schema/transaction scope.
- `models.core.Project`, `Asset`, `User`, `Workspace`, `Membership`, `AuthSession`, `LoginAttempt`,
  `UTCDateTime`, `utcnow` and `new_id` are the persistent primitives.
- `storage.Storage` is the private `put/open/delete` protocol; `make_storage` selects `LocalStorage`
  or `S3Storage`. `S3Storage(bucket, client=...)` supports isolated contract testing.
- `security.Identity`, `require_identity` and `require_csrf` are request authorization dependencies.
- `routes.projects.owned_project`, `project_query`, and `update_project` enforce workspace/active
  filtering and revision CAS. `update_project` joins the caller transaction; the caller commits.
- `errors.APIError` carries safe status/code/message/retryability/details. Durable worker events
  must follow the same no-secret envelope and always carry workspace/project identity.
