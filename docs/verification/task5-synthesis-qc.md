## Natural synthesis product path

The registered `synthesize` stage is command-only. `POST /api/projects/{project_id}/language-tracks/{tag}/synthesize` accepts 1–1000 explicit current source IDs with source-text fingerprints, translation row revisions and audio-selection revisions. The source selection/transcript are guarded. An unapproved target requires an exact current translation-revision review override; this is recorded without approving it. Effective references are owned immutable versions. A line binding wins over its role binding and works without an invented speaker. Measured short/long/overlap warnings are visible in synthesis reads and require the exact effective reference version acknowledgement. Stale/missing/unusable references fail with specific private review errors.

Each selected target line gets its own durable job and per-line output scope. Inference identity contains actual target wording, canonical target/model language, effective binding and reference dependencies, reference audio SHA and immutable corrected transcript/version, connection/model revision and validated effective controls. Track defaults and line overrides have typed immutable versions with CAS roots. Clearing an override is an explicit version. Each non-null controls object is a complete snapshot with documented provider defaults for omitted fields, rather than a patch merged into unknown future defaults. Dormant role bindings and dormant track defaults do not invalidate an explicit line override. Speaker names, target approval/lock revisions, subtitle/gain styling and an independent uploaded-reference timing slot are not paid inference inputs.

Metadata/schema GETs and reference upload happen before the named POST. The resolved host, exact Gradio prefix/API, actual model metadata revision, schema digest, language enum/mapping and uploaded request are checkpointed privately before `Operations.begin`. The real event ID is recorded immediately using the immutable submission binding. Later connection changes cannot redirect polling. Validated terminal FileData is persisted before download. Retry/restart resumes it without another POST. Unknown submission remains blocked until the established explicit acknowledgement.

Returned files undergo bounded-byte validation, actual container/codec/rate/channel/duration inspection, SHA calculation and full decode. PCM16 WAV may be stored directly. Other supported audio is legitimately normalized to verified WAV with raw and normalized metadata retained privately; it is never relabelled WAV by suffix. Every storage write uses the existing prepared-object reservation, settlement and publication machinery. Public facts contain measurements/hashes/reuse and actual IDs, never dialogue/reference wording/provider paths or credentials. No provider token appears in the persisted request.

Validated same-input success is reusable independently of target/source/manual-selection publication guards. Publication may retain a historical output while suppressing current selection with `EDITOR_CHANGED`. A fresh guarded command can select reusable success without another paid request. Default synthesis preserves an existing chosen audio. Explicit replacement and explicit regeneration are audited separately; regeneration bypasses default reuse. A slow generated result cannot overwrite a later manual choice. Natural-output and selection history are immutable and owned by the exact target/line cell.

Reads are bounded to 100 with offsets: current line outputs/outstanding work, request line states, audio output/selection history, and track/line voice-settings history. `PUT .../segments/{id}/audio-selection` requires current source/target/selection CAS proofs and an owned, current natural output. Selection reports `acceptance=not_assessed`; it never approves listening or QC. Duration planning reports measured `natural_duration_ms`, the current `slot_duration_ms`, their ratio, and `ffprobe_full_decode_sha256_v1` provenance. Slot edits recompute planning while retaining unchanged natural audio; changed extracted-reference spans remain stale. No automatic wording/control edits, time stretching, background mixing, loudness finishing or UI were added.
