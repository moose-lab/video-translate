# Task 4B: recoverable source analysis and voice references

Implementation scope: source extraction, remote two-stem separation, remote timestamped source transcription, private voice-reference preparation/versioning, and durable guarded analysis commands. Independent SPEC and QUALITY review remain controller steps. This document is not a live-model or complete-SaaS acceptance report.

## Implemented boundaries

- Production stages are `probe`, `extract`, `separate`, `transcribe`, and CPU `reference`. Translation generation, speech synthesis/QC, finishing/export, and the complete editing workbench are not registered as successful placeholders. They remain tasks 4C, 5, 6, and 7.
- `POST /projects/{id}/workflow` accepts `analyse` and `prepare_media`, with the current timeline `editor_fingerprint`. A probed explicit source selection is required. Media-only preparation never routes unsupported languages into NVIDIA ASR. Analysis ends at source/cast review; `auto_advance` cannot manufacture a missing downstream stage.
- Workflow intents and child associations are durable SQL records. Healthy/current extraction and separation work is shared across equivalent intents, including in-progress work. A stopped accepted or uncertain same-input separation is retained for explicit review/retry, rather than implicitly resubmitted by another intent. Source ASR cannot enter through the generic unguarded run endpoint.
- Source/cast proof includes immutable selection/transcript identity plus current source row revisions and speaker revisions. It excludes target and mix edits. The command rejects an old browser snapshot; the worker checks again before work and the publisher checks under the project lock before domain writes. No source/transcript input key that the publisher changes is used as its own ASR freshness dependency.
- Private operation recovery binds run input fingerprint, request generation, immutable provider revision, resolved host/API prefix, real event ID when returned, terminal FileData, and prepared normalized results. Public facts/events do not contain dialogue, private paths/storage keys, credentials, or provider bodies. There is no invented remote polling ID for synchronous NVIDIA/HF success.
- Demucs schema resolution and generic `audio.wav` upload precede the paid named-call checkpoint. Accepted jobs resume at their saved host/prefix/ID. Terminal FileData is committed before download. Access/transport failures while polling or downloading preserve accepted jobs; only known terminal job/result failures terminate them. Pending observations use durable bounded polling attempts without consuming the transient-error failure budget.
- Synchronous normalized ASR success is committed privately before publication. Lease recovery and explicit retry of a failed publication can reuse that success under the same input fingerprint/generation. Changed inputs rotate the generation; unknown submission outcomes require explicit acknowledgment. Cancellation never claims unsupported remote cancellation.
- Media preparation uses private storage and CPU FFmpeg in the worker. Actual outputs are probed, fully decoded, hashed and bounded. An immutable input's byte count and hash must match its Asset record. Supported demuxers/protocols are allow-listed, with argument arrays and generic temporary names.
- Original uploaded video remains whole. Extraction and all relative transcription/reference times are scoped to the selected window. Working audio is 48 kHz stereo PCM16; ASR preparation is 16 kHz mono PCM16. The 64 MiB working/upload/download limit can reject a long selection; it does not silently shorten the original or selection.
- `POST /references/extract` derives the exact current source row span/text with source/row ownership guards and source/vocals provenance. `POST /references/upload` authenticates before body consumption, bounds audio independently of the JSON editing limit, stages privately, and returns a queued CPU run. MIME alone is not validation. No reference is current before actual decode succeeds.
- Reference versions retain audio hash/Asset, original source track/selection/row and relative/absolute span provenance when derived. Text correction creates an immutable version sharing the audio. Old versions are readable. Uploaded independent references remain reusable across source changes; derived reference freshness follows its actual source dependencies.
- Role defaults and explicit line overrides have separate versioned CAS bindings and readable history. New reference text versions are never promoted implicitly. Future synthesis input resolution includes a line-override discriminator; an explicit override excludes the role-default dependency. Changing defaults therefore cannot stale independent overrides.
- Reference flags are review cues: `short` means under 3 seconds; `silence` is low whole-PCM RMS below 50 on signed PCM16; `overlap` is measured intersection with another known active source timing span. None asserts acoustic speaker purity, noise confidence, or clone quality. Quality remains `review_required`.
- Prepared objects have writing/orphan/published/deleting/deleted lineage. Scoped cleanup reaps abandoned writing reservations after lease expiry and old unpublished generations. Current recoverable prepared caches, live leases, and any published/historical Asset storage key are protected.
